> Элегантный одностраничный сайт для кофейни Brew & Bloom. Адаптивный дизайн, интерактивное меню, галерея с лайтбоксом и форма обратной связи.

## 📸 Превью

| Главный экран | Меню |
|---------------|------|
| *Кофейная атмосфера с parallax-эффектом* | *Табы с категориями блюд и напитков* |

## ✨ Особенности

- 🎨 **Современный дизайн** — тёплая цветовая гамма (кремовый, кофейный, золотой)
- 📱 **Полностью адаптивен** — корректно отображается на всех устройствах
- 🍽️ **Интерактивное меню** — переключение между категориями (кофе, напитки, еда, десерты)
- 🖼️ **Галерея с лайтбоксом** — увеличение фотографий при клике, навигация стрелками
- 📝 **Формы обратной связи** — отправка сообщений и подписка на новости (демо-режим)
- 🧭 **Плавная навигация** — анимированная прокрутка к разделам
- 🔢 **Анимация счётчиков** — плавное увеличение цифр в разделе "О нас"
- 🌟 **Scroll Reveal** — плавное появление элементов при прокрутке
- 🔝 **Кнопка "Наверх"** — появляется при прокрутке вниз

## 🛠️ Технологии

- **HTML5** — семантическая разметка
- **CSS3** — Flexbox, Grid, CSS-переменные, анимации, медиа-запросы
- **JavaScript (ES6)** — интерактивность, табы, лайтбокс, анимации
- **Google Fonts** — шрифты Playfair Display и Lato
- **Unsplash API** — качественные стоковые изображения
